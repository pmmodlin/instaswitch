# instaswitch

Мгновенное переключение раскладки клавишей Caps Lock на macOS.

Штатная опция macOS и утилиты вроде Vorssaint вешают на Caps Lock сразу несколько действий
(короткое нажатие — язык, удержание — Caps Lock, сочетание — Hyper-key) и поэтому ждут, пока
клавишу отпустят. Из-за этого язык иногда меняется с задержкой или не меняется вовсе, если
вы уже нажали следующую букву. instaswitch переключает язык **сразу при нажатии**, без
каких-либо условий.

| Клавиши | Действие |
|---|---|
| Caps Lock | следующая включённая раскладка (ABC ↔ Русская) |
| Shift + Caps Lock | обычный Caps Lock |

## Как это работает

1. `hidutil` переназначает Caps Lock в F18 на уровне HID, поэтому системная логика Caps Lock
   (задержка, удержание, штатное переключение на ABC) больше не срабатывает.
2. Event tap ловит нажатие F18, сразу вызывает `TISSelectInputSource` и проглатывает
   событие, так что F18 не доходит ни до одной программы. Модификаторы и другие зажатые
   клавиши не учитываются, автоповтор игнорируется.
3. При подключении нового устройства переназначение применяется заново.
4. При остановке демон снимает переназначение, и Caps Lock возвращается в обычное
   поведение. LaunchAgent с `KeepAlive` перезапускает демон, если тот упал.

## Установка

```bash
./install.sh
```

Скрипт собирает `~/Applications/Instaswitch.app` и запускает его как LaunchAgent
`com.pmmodlin.instaswitch`. При первом запуске выдайте Instaswitch доступ в «Системные
настройки → Конфиденциальность и безопасность → Универсальный доступ». Пока доступа нет,
Caps Lock не переназначается.

Сборка подписывается ad-hoc, поэтому после каждой пересборки macOS может снова запросить
доступ. В этом случае удалите старую запись Instaswitch из списка и добавьте её заново.

Лог: `~/Library/Logs/instaswitch.log`.

## Удаление

```bash
./uninstall.sh
```

## Ограничения

- В полях ввода пароля (Secure Input) macOS сама держит ABC и не пускает event tap.
- Если включён Super key в Vorssaint или аналогичная функция в Karabiner, отключите её:
  они тоже переназначают Caps Lock.
